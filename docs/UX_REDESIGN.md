# 初めて使う人のための画面整理

既存の権限とサーバー側の予約・出欠・公開・請求処理を維持し、画面の構成と操作案内を変更します。

| 提案 | 対応 |
|---|---|
| 1 メニュー | 日常業務を優先し、登録・設定や低頻度業務は開いて選ぶ |
| 2 ホーム | 今日の業務リンクと未対応業務を先に表示 |
| 3 用語 | メニューとページ見出し、児童情報の名称を統一 |
| 4 説明 | 使い方と連携詳細を必要時に展開 |
| 5 ボタン・見た目 | 強い影・太字・装飾を抑え、主操作と補助操作を整理 |
| 6 保存 | 手動保存の未保存件数を下部にも表示、自動保存の状態は読み上げ対象に |
| 7 予約 | 手順を表示し、提出前に変更日の送迎・取消し内容を確認 |
| 8 保護者スマホ | 予約・予定・連絡帳の下部メニュー、保存バーとの重なりを回避 |
| 9 児童情報 | 既存のURL連動タブを維持し名称を整理、アレルギー内容をヘッダーに表示 |
| 10 連絡帳 | 職員専用記録を含めず、保護者向け本文を保存前にプレビュー |
| 11 表のスマホ | 迎え／送りを切り替え、隠れた列への貼り付けを防止 |
| 12 初回・空画面 | 準備手順・端末内チェックリスト・児童登録への案内 |

チェックリストは端末内の手動確認用で、サーバーの設定完了判定ではありません。
連絡帳プレビューは入力中の本文・食事・体調の確認用で、保護者アプリの全画面の再現ではありません。
学校日・休業日・未設定、公開・連携・確認印の区別を維持します。

## 検証

- UCRMのVite本番ビルド、既存JavaScriptテスト18件。
- 実コンポーネントのDOM操作でメニュー、チェックリスト、本文プレビュー、送迎切替・保存を確認。
- 既存のPC／スマホのブラウザ試験の見出し・操作を新画面に合わせ、チェックリストとプレビューの試験を追加。
- この作業環境にはPHPと動作可能なChromiumがないため、Laravel・実ブラウザ試験はCIで確認が必要。
- 初見の職員・保護者による操作評価とMac miniのデモ反映は別途確認が必要。
