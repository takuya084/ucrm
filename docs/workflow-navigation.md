# アクセスはシンプルに、把握は一目で

- 業務内容確認は確認のホーム。利用児童・スタッフ全員の送迎・療育準備・未対応を表示し、直接入力・編集するボタンは置かない。未対応の件数は、同日・同じ未対応条件で絞った専用一覧へリンクする。
- 入力の入口はサイドメニューの業務名に統一する。記録・連絡帳は「記録・連絡帳」、送迎の変更は「送迎一覧」。
- 一覧→詳細・入力→同じ一覧へ戻る、という業務内の移動は残す。URLを直接開くことを制限する機能ではない。
- 日付のある業務はサイドメニューで対象日を引き継ぐ。モバイルも同じメニューを使う。
- ホームは未入力・未対応の件数と確認先を表示し、児童名や状態の詳細は絞り込んだ専用一覧で確認する。支援記録（内部記録）と連絡帳（保護者向け）は同じ編集画面でも別々に判定する。
- 保存・公開・連携・保護者の確認印は別の状態。ホームでは出欠保存済みの選択日を集計し、出欠未保存ならその旨を示す。
- 管理者・児発管には期限アラート、同意待ち、問い合わせ、前月請求、月をまたいだ未入金・返戻・過誤申立の残件も表示する。一般職員への権限拡大はしない。
- メニューへの案内は「入力先：メニュー『出欠・利用実績』」のように場所を示し、メニュー名自体をリンクにする。案内と実際のサイドメニュー名は必ず一致させる。
- 未対応業務の件数から詳細へ進めるので、ホームに「対応が必要な児童」「全児童の状況」の重複一覧を置かない。
- 職員・管理者／児発管・事務は見出しと色で区別する。各項目の見出し装飾も統一する。アレルギーの「特記事項なし」等は表示を省くが、保存値や実際の注意事項は変えない。

確認：PC・モバイルで、ホームの未対応把握→サイドメニュー→対象日の一覧→入力・保存→一覧→ホームの状態更新を検証する。送迎はホームで全員分を閲覧でき、専用画面で変更できることを検証する。

## 補助機能の段階表示

常に見せるものは、業務の一覧・未対応・重要な注意・主な保存操作。追加・削除・一括変更・CSV登録・連携設定・年間出力・詳しい説明・運営指標は、内容が分かる見出しのアコーディオンにまとめ、最初は閉じる。専用設定画面や入力画面の主な入力欄まで隠さない。

開閉は共通の短いアニメーション。閉じた内容はTab移動・読み上げの対象から外す。閉じても入力値は消さず、未保存表示は閉じた外側に残す。動きを減らすOS設定ではアニメーションを止める。送迎の共通グリッドも同じ扱いにし、p-yoyakuとUCRMで実装を揃える。
