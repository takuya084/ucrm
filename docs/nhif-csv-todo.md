# 国保連CSV インタフェース仕様準拠対応 TODO（P2-6）

現状の `NhifCsvExportService` は独自形式（レコード種別 1/2/3/9）であり、
**国保連の電子請求受付システムには取り込めない**。転記用の内部資料としてのみ使用可能。

## 対応に必要な公式資料（最新版を入手すること）

1. 国保中央会「電子請求受付システム インタフェース仕様書（障害児支援・事業所編）」
2. こども家庭庁 告示「障害児通所給付費等単位数表」（令和6年度改定版）
3. 「障害児通所給付費等の請求に関する留意事項通知」
4. 都道府県国保連合会の「請求事務マニュアル」（媒体・伝送の運用ルール）

## 実装すべきファイル種別（インタフェース仕様書に基づく）

| ファイル | 内容 | 備考 |
|---|---|---|
| 請求書情報 | 障害児通所給付費請求書（市町村ごとに集計） | 様式第一 |
| 明細書情報 | 障害児通所給付費明細書（児童×月） | 契約情報・上限管理結果・日数内訳を含む |
| サービス提供実績記録票情報 | 日別の提供状況・時間・送迎・保護者確認 | 様式（放デイ/児発で別様式） |
| 利用者負担上限額管理結果票情報 | 上限管理事業所が作成 | 管理結果1/2/3と事業所別内訳 |

## 守るべき仕様上の要点

- 制御レコード（ボリュームヘッダ等）+ データレコード + エンドレコードの構造
- 項目番号・桁数・型（数値は前ゼロ、日付は和暦/西暦の指定に従う）の固定レイアウト
- 文字コード Shift_JIS、改行 CRLF
- 市町村番号（6桁）ごとのファイル分割または集計
- 事業所番号10桁・受給者証番号10桁のチェック
- 取込送信システム/簡易入力システムでの事前検証を CI に組み込むことを推奨

## 既存コードとの接続点

- `app/Services/Billing/NhifCsvExportService.php` を仕様準拠の Writer 群に置換
- 必要データは P2 対応で揃っている:
  - 契約情報: `contracts`
  - 上限管理結果: `billing_details.cap_management_result_code` ほか
  - 無償化・軽減: `recipient_certificates.is_free_of_charge` ほか
  - 時間区分: `support_plans.planned_duration_minutes` → conditions.time_category
