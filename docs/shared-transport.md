# p-yoyakuとの送迎担当共有

「今日の業務」の「スタッフ全員の送迎」にp-yoyakuの当日予約・担当を表示します。出席記録の保存前後で同じ一覧を使用し、未割り当ても表示します。一般職員が閲覧でき、管理者・児発管が担当を変更できます。

担当職員の候補はp-yoyakuの同一事業所に登録した先生です。p-yoyakuの日別予約詳細とUCRMのどちらから変更してもp-yoyakuに保存されます。職員名やIDを自動照合しません。

導入順はp-yoyaku PR #30を反映してマイグレーション、次にUCRMを更新します。既存の連携URL・事業所ID・APIトークンを使います。未連携の事業所では従来のUCRM内登録を使用します。

編集していない間は30秒ごとに更新します。「最新の担当を確認」でも更新できます。他の画面で変更された担当を古い画面から保存するとエラーになり、一覧の更新と選び直しを案内します。接続できない場合は取得失敗を表示し、UCRM内だけに保存して成功扱いにはしません。

従来UCRM内だけに保存した担当は残します。連携後はその件数を案内するため、共通一覧で担当を選び直してください。時刻・場所はp-yoyakuの予約で編集します。親送迎と送迎時刻のない予約は担当割当の対象外です。
