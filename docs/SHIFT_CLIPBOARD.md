# シフト表・勤務パターンのコピーと貼り付け

プルダウンはそのまま使えます。選択中の勤務区分や開始時刻を⌘/Ctrl+Cでコピーし、⌘/Ctrl+Vで貼り付けます。Shift+クリックまたはShift+矢印キーで範囲選択します。

Excelは「勤務区分・開始時刻」の2列を職員ごとに並べ、行に日付（勤務パターンは月〜日）を置きます。貼り付けは選択範囲の左上を起点にします。反映後は「保存」を押してください。

未登録の勤務区分、06:00〜22:45の15分刻み以外の時刻、休み系区分と開始時刻の組み合わせ、範囲のはみ出しは警告を出して全体を拒否します。空欄はクリア、9:00は09:00として扱います。貼り付け中の一部だけを保存することはありません。サーバー側も勤務区分・時刻を検証します。

## 確認用データ

`demo:shift-samples`は標準のオフラインデモ専用です。既存事業所には触れず、「【デモ】シフト確認用（職員10名）」を新設します。既存の同名データがあれば上書きせず中止します。通常の本番環境では実行できません。

管理者・児発管・常勤・午前/午後パート・理学療法士・研修修了職員・送迎担当の10名、早番・遅番・午前・午後・送迎・休み・有給の7区分、曜日別の勤務70件、12名の架空児童の利用曜日と2か月分の下書きシフトを作ります。有給、職員不足、児発管不在、有資格者不足、休業日を日別備考で見分けられます。配置チェックは現在の画面の参考表示の確認用です。

ログイン用パスワードはランダム生成し、実行時の出力にだけ含めます。メール送信や外部連携は行いません。DB初期化・マイグレーション・既存データを削除するShiftSampleSeederは使いません。
