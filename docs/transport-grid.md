# 送迎一覧の一括編集

p-yoyakuの「日別の送迎一覧」と、連携済みUCRMの「今日の業務 → 送迎一覧」は同じ編集コード・列順です。

1. 当日予約を一覧で確認します。予約を追加する児童は「追加する児童」から行を追加します。
2. セルで候補を選ぶか、Excelの時刻・場所・担当の範囲をコピーして左上のセルへ貼り付けます。児童列は貼り付け対象外です。
3. 複数の児童にチェックを付け、列と値を指定して一括適用できます。Shift＋クリックまたはShift＋矢印で選んだ範囲はコピーできます。
4. 不正な時刻・場所・職員は赤いセルで修正します。時刻は事業所の設定範囲の5分刻みです。場所は既存の予約区分（学校・自宅・親送迎・その他）に限定し、当該児童の登録済み学校名・方面名も区分へ照合します。新しい場所や職員は貼り付けから自動登録しません。
5. 「変更をまとめて保存」で変更行を一括保存します。途中に入力エラーや同時編集の競合があれば全件未保存とし、入力を残します。

選択行の削除は児童のアカウント削除ではなく、当日予約の取り消しです。保存前の削除予定は取り消せます。保存時に件数を確認します。新規予約は従来どおり翌月・休業日以外に限定します。既存予約の編集は従来の管理者編集と同じく過去月にも対応します。

通信が切れた場合は保存結果を断定しません。入力を控え、最新の一覧を再取得してください。編集中の自動更新は行いません。管理権限は従来どおりで、UCRMの一般職員は閲覧専用です。

導入順はp-yoyakuの更新、続いてUCRMの更新・フロントビルドです。この機能のための新規マイグレーションはありません。両アプリのpublic/transport-grid/grid.jsとgrid.cssは同一内容で更新します。
